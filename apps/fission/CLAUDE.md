- `src/frame-guard.ts` (audit S10): imported first by both entry scripts; inside a frame (any origin) it shows only a refusal with a link that opens the app on its own and throws, so nothing mounts, no kernel worker starts and storage is never read. `index.html` carries the Content Security Policy (scripts only from this site plus WebAssembly, no plugins, `<base>` or form targets; connect-src left open for the AI providers; a meta policy can't set frame-ancestors, hence the guard). `e2e/framing.mjs` browser check of both: another site framing the app invisibly, with `?guide`, and the app framing itself (the refusal, no worker, no .wasm, no store), the link at 375 px with taps, the unframed controls, and under the real policy an inline script, another site's script, a plugin and a `<base>` refused by name, fetch to another site allowed, WebAssembly compiled on the page and the kernel's box volume.
- `e2e/leave-save.mjs` (timeline hunt finding 1): changes made and left at once, while the top bar still says Saving…, come back: a width reloaded at 1280 px and 375 px with taps, the hunt's Box, Sketch 1, Extrude 1 and Go to the start reloaded, a burst of widths and the tab closed with no question; with localStorage refusing the journal, a saved page closes without asking and one with a change waiting asks first. In `npm run e2e` and `e2e:engines`.
- `e2e/monkey.mjs` (with `monkey-core.mjs`): the seeded monkey tester, random user actions in the Design workspace (from 25a3 a double-click on a bar item or browser row too, so Edit Sketch is reached) with the app's invariants checked after every one and failures shrunk to a short list (`e2e/monkey-results/`). Replays `e2e/regressions/monkey-*.json`, then seeds 1-3 at 60 actions (about 2 minutes); last in `npm run e2e`. `e2e/monkey-plants.mjs` (run by hand) proves it catches each planted bug; `monkey.test.mjs` (in `npm test`) checks the plants still apply.
- `e2e/browser.mjs`: the one launcher for the browser tests (Chromium, or `E2E_BROWSER` = firefox / webkit; testing catch-up TC4). Contexts it opens bypass the CSP unless given `bypassCSP: false`, since Playwright's waitForFunction evaluates a string in the page, which the policy refuses (WebKit's bypass ignores a meta policy, so there the page is served without the tag); `framing.mjs` checks the real policy. `e2e/sketch-screen.mjs`: sketch millimetres to screen (`HOME`, `TOP`, `screenPoint`) and `clickPlane`, which fails if anything but the canvas is on top of the point (the view cube covers (50, 40) at 1280 × 800).
- `e2e/sketch-session.mjs`: a long messy sketching session (TC2), seeded (`FISSION_SEED`, `E2E_SESSION_SHAPES`, default 50): line, rectangle and circle tools by key, Escapes, bursts of undo and redo, half undone, Save compared with the model, reload (back from the browser's store), the file opened in a fresh tab, Sketch 2, then a closed house in Sketch 3 extruded to the model's volume; every step checked against a coordinates model with the outline words from `packages/testing/src/outline-model.ts`. Failing seeds go in `e2e/regressions/sketch-session-<seed>.json` and replay.
- `e2e/sketch-pixels.mjs`: screenshot checks of a sketch (TC3): pixel probes in every browser (sketch-line pixels along each line and the circle where `sketch-screen.mjs` puts them, none 8 px beside them; the same probes for the drawing moved 1 mm must fail), and in Chromium golden images of the canvas while drawing and after Finish (`e2e/screenshots/*-chromium.png`; at most 50 pixels may differ by more than 32 in a channel; the canvas moved 2 px must fail; `E2E_UPDATE_SHOTS=1` rewrites them, a failure writes `*.actual.png` and `*.diff.png`, which CI keeps). `e2e/png.mjs`: PNG read and write with no packages, and `compareImages`; `e2e/png.test.mjs` (`npm test`): the five row filters by hand, the comparer at 0.9× and 1.1× of both thresholds.
- `npm run e2e:engines`: the browser tests the CI job `browsers` runs in Firefox and WebKit (`E2E_BROWSER`), each to the end even if one fails: undo, sketch, sketch-tool, sketch-session, sketch-pixels, extrude; the job also runs the smoke test there, reported only for now. Firefox runs there with a window on a virtual screen (`E2E_HEADED=1` under xvfb-run) for software WebGL. `check(name, fn, known)` in `sketch-tool.mjs` marks a known app bug per engine: the check must keep failing with that symptom, and fails once it passes, until the fix removes the mark.
- `licences.mjs` (audit L2): the third-party licence notices and the licence allowlist. `vite.config.ts` runs its plugin, which writes `third-party-licences.txt` beside the built app (npm packages the app needs at run time, from the lockfile; Rust crates compiled into the kernel's .wasm, from `cargo metadata`; code copied inside a package, `EMBEDDED`, kept by hand) and fails the build when a bundled file's package isn't listed or a bundled file names a copyright holder the notices don't. `ALLOWED` is the list every npm package and crate, development-only ones too, must be under; a new licence waits for the owner. The guide's Licences link opens the file. `e2e/licences.test.mjs` (in `npm test`, so it is the CI licence check): hand-worked SPDX reading, 3,000 seeded expressions against plain AND/OR logic, licence file choice (the unicode-ident AND regression), the lockfile and crate walks on made-up trees, the build plugin's refusals, and this repository held to `ALLOWED`.
- `e2e/monkey.mjs` (from 25a5): also checks that new ids come from the counter (unless the document was seen before) and that an Edit feature step changes only its item; `MONKEY_FOCUS=edit` weights item menus and double-clicks.
- `e2e/hidden-edges.mjs`: browser check that lines behind a body stay hidden (an extruded sketch's back lines, a sketch line passing behind the body) while ones beside it are drawn, and that an edge under a sketch line keeps its hover and selection colour; 1280 px and 375 px with taps; in `npm run e2e` and `e2e:engines`.
- `e2e/navigation.mjs` also checks that an orbit stops when let go (the 25a5 flick). `e2e/smoke.mjs` split view checks: every choice in the second pane at 1280/375 (one toolbar row, no band, placeholders show "Coming soon" and draw no 3D view), with breaks; `fissionTest.splitView()`. `e2e/timeline.mjs` (24f4): a design with no body (both solids suppressed, every item deleted; the panel's words, STL's note, a width adding a box; emptied, reloaded and a square extruded on it).
