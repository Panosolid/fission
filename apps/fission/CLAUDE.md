# The app shell

Contents of `apps/fission`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- the app shell (`src/main.ts`: top bar with Save/Open (behind Menu at phone width) and the save status, workspace switcher, the toolbar/browser/properties slots around the shared viewport, Split's second pane with slots of its own, drop and paste of files (`receive`, through `routeFiles`), and a change-notes strip over each pane's viewport for the workspace in that pane; `?test-hooks` gives the browser test `window.fissionTest`; `#design`, `#slice`… links open a workspace), `e2e/smoke.mjs` browser test, `e2e/dump-viewer.mjs` browser check of the kernel's failure-dump page, `e2e/storage.mjs` browser check of the IndexedDB store, `e2e/image.mjs` browser check of the Image workspace, `e2e/files.mjs` browser check of dropping and pasting files, `e2e/copy-svg.mjs` browser check of copying a profile as SVG (the verb, Ctrl+C, the clipboard's two types; all run by `npm run e2e`).
