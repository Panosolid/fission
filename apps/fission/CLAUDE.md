# The app shell

Contents of `apps/fission`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- the app shell (`src/main.ts`: top bar with Save/Open (behind Menu at phone width) and the save status, workspace switcher, the toolbar/browser/properties slots around the shared viewport (warm workspaces, X7: each mounted workspace has slot elements of its own, swapped into the page while shown; `WarmPool` decides mount, sleep, wake, unmount), Split's second pane with slots of its own, drop and paste of files, and the top bar's Open (`receive`, through `routeFiles`; Open's picker accepts every format with an importer), the one shortcut table dispatched to the workspaces on screen (pane in use first) and the shortcuts list (`?`), the one undo history (step 20b: `createHistory` over `projectToJson`, `restoreSnapshot` re-mounts what is on screen, `mountingDone` amends defaults filled in while mounting, the Undo/Redo buttons and keys; at phone width `placeUndoRedo` docks the pair in the main viewport's corner, 20c), and a change-notes strip over each pane's viewport for the workspace in that pane; `?test-hooks` gives the browser test `window.fissionTest`; `#design`, `#slice`… links open a workspace), `e2e/smoke.mjs` browser test, `e2e/dump-viewer.mjs` browser check of the kernel's failure-dump page, `e2e/storage.mjs` browser check of the IndexedDB store, `e2e/image.mjs` browser check of the Image workspace, `e2e/files.mjs` browser check of dropping and pasting files, `e2e/copy-svg.mjs` browser check of copying a profile as SVG (the verb, Ctrl+C, the clipboard's two types), `e2e/switching.mjs` browser check of switching (under 100 ms click to painted frame, the same page on return, no duplicate ids with split view), `e2e/shortcuts.mjs` browser check of the shortcut table (the list, modal Escape, sleeping workspaces hear nothing, typing in a field, split view), `e2e/undo.mjs` browser check of Undo and Redo (buttons, labels, merging, keys, text fields, workspace switch, the selection and camera through undo, phone placement), `e2e/sketch.mjs` browser check of saved sketches (step 21b: a file with a sketch shows it in the timeline and the Sketches group at 1280 and 375 px, keeps it through a part edit, Undo and Save; a version 1 file opens; step 22b: a part extruding a one-circle sketch opens as 1000π mm³; `E2E_SHOTS` saves screenshots), `e2e/sketch-tool.mjs` browser check of the sketch tool (step 21c: plane prompt, a rectangle drawn by clicks and closed, Ctrl+Z on one line staying in the sketch, typed and refused grid sizes, Escape, Finish, the same at 375 px with taps; step 22a: the rectangle tool by R and its button, the row note, one undo step, Escape, L, extruded to 12,000 mm³, at 375 px), `e2e/extrude.mjs` browser check of Extrude (step 21d: from the sketch panel and the toolbar, a refused distance records nothing, 12,000 mm³ as one undo step framed in 3D, the typed distance, Undo/Redo, a preset after it, an open sketch and no sketch keep OK off with the reason, Escape, the same at 375 px with taps), `src/assistant.ts` the AI assistant panel (AI2: provider settings and key entry, first-send confirmation for a remote provider, ask, preview, Accept as one "AI: …" undo step through Design's `run`, Reject), `e2e/assistant.mjs` browser check of the assistant (fake Ollama and API answered by page.route: preview changes nothing, accept/undo/redo, reject, stale preview refused, retry failure, first-send confirmation, key only to its provider, settings kept, weak graphics card), `e2e/journeys.mjs` magic-moment journeys (clicks and seconds per ready journey in `MAGIC_JOURNEYS`, judged against their limits; the rest listed as pending; all run by `npm run e2e`).
- `e2e/browser.mjs`: the one launcher for the browser tests (Chromium, or `E2E_BROWSER` = firefox / webkit; testing catch-up TC4). `e2e/sketch-view.mjs`: sketch millimetres to screen (`HOME`, `TOP`, `screenPoint`) and `clickPlane`, which fails if anything but the canvas is on top of the point (the view cube covers (50, 40) at 1280 × 800).
- `e2e/sketch-session.mjs`: a long messy sketching session (TC2), seeded (`FISSION_SEED`, `E2E_SESSION_SHAPES`, default 50): line, rectangle and circle tools by key, Escapes, bursts of undo and redo, half undone, Save compared with the model, reload (back from the browser's store), the file opened in a fresh tab, Sketch 2, then a closed house in Sketch 3 extruded to the model's volume; every step checked against a coordinates model with the outline words from `packages/testing/src/outline-model.ts`. Failing seeds go in `e2e/regressions/sketch-session-<seed>.json` and replay.
