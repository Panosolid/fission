# Design workspace

Contents of `workspaces/design`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- the CAD workspace (`workspace.ts`, which names each undo step: "Change width" merged per size box, "Change shape to …"; a mount by Undo or Redo keeps the camera and compares the selection with `lastBuilt`, the body it last built; `profiles.ts` ready-made outlines until the sketcher).
- `document.ts`: Design's data, version 2 (step 21b; docs/document-model.md, docs/project-format.md): `nextId`, profiles, sketches (curves: lines, circles round a point id from step 22b, arcs from a start to an end point id counter-clockwise round a centre point id from step 23a; `curvePoints`) and the timeline; `lastFeature` is the part's one solid feature (the last item that is not a sketch); `withPart` replaces it and keeps the sketches; `readDesignDocument` migrates version 1 (`migrateDesignV1`) and checks every sketch rule; `shown` names a file's value in a message without running its own `toString`.
- `sketch.ts`: sketch edits as pure document functions (`addSketch`, `drawLine` with ends as a point id to share or new coordinates, `drawRectangle` (step 22a: four chained lines, corners on existing points shared; `pointAt`), `drawCircle` (step 22b: round a point id to share or new coordinates, radius above 0), `drawArc` (step 23a: start, end and centre each a point id or new coordinates, ids taken in that order; one undo step "Draw arc"), `deleteCurve` dropping points only it used, `movePoint`), each one undo step named in `SKETCH_STEPS`; ids from the counter, never reused; `planeOf` the origin planes' frames; `sketchOutline` asks the kernel (`sketch_outline` with `sketchCurves`, the lines, circles and arcs apart, through `askOutline`) each time, never stored; `sketchLines` is the lines alone. Sketches are `design.sketch` objects with the generic `outlineProducer` (`representations.ts`, `designObjects(doc, kernel)`), timeline rows and rows of the browser's Sketches group ("sketches/<id>").
- `sketch-tool.ts`: the sketch tools as pure functions: `SKETCH_TOOLS` (Line, Rectangle, Circle, Arc with keys L, R, C and A, steps 22a, 22c and 23b), `startTool`, `toolBusy` (what Escape ends), `clickAt` (line: a click at a kernel-snapped point draws a chained line sharing its start, landing on an existing point ends the chain; rectangle: first corner, then the opposite one, refused with a `note` on its row or column; circle: the centre (an existing point shared), then a point on the circle, the radius `distance` between them, refused with a `note` on the centre; arc: start, end, then a point on it, through `arcThrough` (step 23b: the centre on the line midway between the ends, ends swapped so it runs counter-clockwise, `null` within a rounding bound of one line), refused with a `note` for no end or no bend), `drawStep` (the undo step's name), `previewLine`, `previewSegments` (what a click would draw), `circleSegments` (a circle as `CIRCLE_SEGMENTS` = 64 segments, drawing only), `arcSegments` (step 23a: an arc in ⌈64 × turn / 2π⌉ segments from its start to its end exactly), `sketchDrawings` (what the viewport draws: lines, then circles, then arcs, as segments), `curveCount` (the status's "4 lines and 1 circle", "2 lines, 1 arc and 1 circle"), `ORIGIN_PLANES` (only XY offered until 24), `PLANE_VIEWS`. `sketch-panel.ts`: the panel at the top of the properties (Pick a plane, then the tool buttons with `TOOL_HELP`, grid, outline status, Finish sketch); styles in `src/styles/sketch.css`. `workspace.ts` runs the mode: Create sketch button, plane pick, `applySketchEdit` (one undo step per edit), Escape ends a chain or drops a first corner, centre or arc ends, `chooseTool` (buttons, L, R, C and A), `editingSketch` keeps you in the sketch, with its tool, through Undo and Redo.
- `extrude.ts`: extruding a sketch (step 21d): `extrudeSketch` (a new feature after the sketch, depending on it, replacing the part's solid feature until step 32; undo step `extrudeStep`), `setExtrudeDistance` (`DISTANCE_STEP`), `featureSpec` (the BodySpec of any feature; an extrude of a sketch asks the kernel for the outline at every build, so sketch edits rebuild it). `partOf` names it `sketch-extrude`; the panel shows only its distance (the height box). `extrude-panel.ts`: the Extrude panel (sketch, typeable distance, the kernel's closed/open answer, OK off until closed, Cancel and Escape); styles `src/styles/extrude.css`. `workspace.ts` opens it from the toolbar's Sketch group and the sketch panel (which finishes the sketch first), builds before recording, and rebuilds the part after an edit to the sketch it extrudes.
- `graph.ts`: the timeline in the project graph (`syncGraph`); every change and removal is recorded as a change note with `changeWords` ("you changed the box", "you removed the profile").
- `shortcuts.ts`: Design's keys in the one shortcut table (Escape clears the selection, Ctrl+C copies a selected profile as SVG, L, R, C and A choose sketch tools while a sketch is edited, `sketchToolKey`) and `designShortcut`, what each does for a selection; `workspace.ts` runs them in `shortcut`.
- `actions.ts`: Design's verbs: Download STL for a body, Copy as SVG for a profile (through the representation registry, then core's `outlineToSvg`; also Ctrl+C with one profile selected, through `shortcuts.ts`). `references.ts`: `designReference` for bodies, faces, edges; `profileReference` ("outline:profile-1") for a profile, selectable from the browser's Profiles group (`browser.ts`); `selection.ts` names it and drops it when the part has no profile.
