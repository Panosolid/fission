- [x] G2a. Image hands each layer over as an Image (done 2026-10-16): `representations.ts` registers an `image.layer` producer in the one registry (the importer moved there too) and the plugin declares `produces: ["image"]`; `imageObjects` / `currentImageObjects()` give live handles that read the open image at each delivery, so an edit reaches every receiver and a layer that is gone is refused; the pixels are the layer's with its adjustments, a fresh copy each time, and a hidden layer still hands over its pixels (Hide is a view inside Image, so an engraving can't vanish); `checkImageRep` refuses a broken Image with the same limits as opening a file. Verified: `test/representations.test.ts` (hand-worked +20 % on 100 and 240 grey gives 151 and 255 at 0.1 mm a pixel; live DPI and Brightness edits; copy safety; gone layer and no image; a target that takes no images; each break of an Image; 0.9×/1.1× of the smallest pixel and the 1 km width; 200 seeded cases against a simple Brightness model, seed 2026); five deliberate breaks of the producer each failed their tests. One line in `packages/testing/test/workspace-api.test.ts` adds `image.layer` to the types it checks.
- [ ] G2b. Trace an image to outlines (Image → Outline converter, integration map row 14). Owner's decision (2026-10-16): build it in the kernel, as a high-effort kernel thread started by the coordinator once the test-audit kernel fixes have merged (and after X6b, which changes the Outline code). Plan:
  - Kernel tracing: threshold the pixels, follow the pixel edges into closed contours, then fit lines and arcs (biarcs, the curve type the integration map chose for Vector) within a tolerance in mm, so a traced logo is an exact outline you can extrude or laser-cut, not a staircase.
  - One region list: the outline format (`Outline` in `packages/core/src/kernel/kernel-types.ts`, `OutlineRep` in `packages/core/src/model/representation.ts`) grows to hold many separate shapes, each with its holes (the inside of an "O"), changed once in the kernel and core.
  - Trace what you see: the input is G2a's `image.layer` Image (after Brightness, through the live link), with one threshold slider; tracing the same image twice gives exactly the same result.
  - Limits that refuse instead of freezing: caps on the number of shapes and curve pieces, with a clear message when a busy photo would pass them.
  - Tests: hand-worked cases (a square traces to exactly 4 lines, a circle to arcs within the tolerance), the traced area matching the pixel area, seeded random blobs against a simple model, deliberate breaks, the 0.9×/1.1× tolerance boundary, and the tracer in the nightly fuzzing; added to the stateful harness the day it lands.
