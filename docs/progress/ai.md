## AI4. Better instructions, checked on held-out cases (one PR)
- [x] AI4.   Scores (right answers, GitHub runner CPU, set_part only; original 12 / held-out 14), all judged on the final part:
  before: qwen2.5:1.5b 8/12, 4/14; llama3.2:3b 8/12, 4/14; gemma2:2b 2/12, 5/14.
  after: qwen2.5:1.5b 8/12, 6/14; llama3.2:3b 11/12, 8/14; gemma2:2b 3/12, 2/14.
  (Two earlier tries, scored with the old command-by-command matcher: v1 descriptions only, qwen 6/12, 4/14 and llama 11/12, 8/14; v2 plus "give every parameter a value", qwen 6/12, 2/14. The zeros from "ignored" sizes are what optional sizes fixed.)
