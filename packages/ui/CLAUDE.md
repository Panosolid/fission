# UI kit

Contents of `packages/ui`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- shared UI kit: number formatting, theme (`theme.css`: the base layout, including split view; each feature's own styles are `src/styles/<feature>.css`, every selector starting with `.<feature>`, loaded by the app without a list), workspace switcher, split choices (`split.ts`), the warm-workspace pool (`warm.ts`, X7: one mounted instance per workspace, living in one pane, asleep unless shown), the link badge, the downstream chip (`downstream-chip.ts`), the file-drop outline (`styles/file-drop.css`, X6a) and the change note (`change-note.ts`; the strip of notes the shell shows over each pane is styled in `styles/notes-strip.css`), the keyboard shortcuts list (`shortcut-list.ts`, `styles/shortcut-list.css`, X7b), the top bar's Undo and Redo (`styles/undo-redo.css`, step 20b), the AI assistant panel's styles (`styles/assistant.css`, AI2), the guide's styles (`styles/guide.css`; the guide itself is in packages/viewport `src/guide/`), placeholder page.
