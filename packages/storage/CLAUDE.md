# Storage

Contents of `packages/storage`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- projects kept in the browser. `store.ts` (`projectStore(kv, readers, now)`: list, open, save, remove; each project is `project/<id>`, its exact .fission.json text, and `summary/<id>`, name and save time; open goes through `projectFromJson`) over the `KeyValue` interface in `key-value.ts` (`memoryKeyValue()` for unit tests); `indexeddb.ts` is the thin browser adapter, checked by `apps/fission/e2e/storage.mjs`; `localStore(readers)` is the two together; `autosave.ts` (`startAutosave`: saves a quiet moment after each `changed()`, one save in flight, reports "saving"/"saved"/error; tested on a fake clock; `leaving()`, called by the shell when the page is hidden, reloaded or closed, writes changes not stored yet to the journal and starts the save at once, false when it can't keep them so the page asks before going); `unsaved.ts` (the unsaved-changes journal in localStorage, `panoshape.unsaved/<id>` holding the file text, removed once the store holds that state or newer; `recoverUnsaved` puts entries back before the app lists projects; seeded page-life runs in `test/unsaved.test.ts`). Workspaces call `ctx.projectChanged()` after writing `ctx.project`; the shell autosaves on it.
