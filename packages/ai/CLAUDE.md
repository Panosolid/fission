# AI assistant

Contents of `packages/ai`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- the optional AI assistant (docs/ai.md): `providers.ts` (`PROVIDERS` text, `createProvider`, `detectProviders`, `pickLocal` (AI6: which local one to pick), `listModels` and `chooseModel`; each takes `ProviderDeps` so tests pass stand-ins for fetch, WebGPU, WebLLM and the built-in model), `ollama.ts` (Ollama's /api/chat, schema as `format`; `isThisComputer`: an address that isn't this computer makes it remote, `sendsAway` and `askBeforeSending` in `providers.ts`, tested in `test/ollama-remote.test.ts`, audit S3), `hosted.ts` (own API key: Anthropic via a forced tool, OpenAI via response_format, any OpenAI-compatible https endpoint; `vendorFromKey`, `listHostedModels`), `local.ts` (in-browser WebLLM model with the graphics-card check and download size; the browser's built-in model), `http.ts` (one request helper: time limit, no cookies or referrer, errors never contain the key), `keys.ts` (keys in localStorage filed by the origin they are sent to), `prompt.ts` (`systemPrompt`: the offered commands with what each parameter means, written out because constrained output never shows the model the schema's descriptions, then the unit, radius and cube rules; tested in `test/prompt.test.ts`); `test/models.test.ts` covers AI6 (key prefixes, model lists, picking); tests use `test/fakes.ts` (a fake server and a seeded generator), never a real model; `askForCommands`, `buildContext`, `acceptCommands` (accepted commands as one "AI: …" undo step, all or nothing; `actions.ts`), specialist models and per-workspace plans; the panel itself is `apps/fission/src/assistant.ts`.
